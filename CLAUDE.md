# Project: AI career learning (RAG Mastery)

The learner is following `RAG-Mastery/` (50 study days, about 2 hours/day) to become an AI engineer.

## Rules for Claude in this folder
- Read `RAG-Mastery/PREFERENCES-AND-IMPROVEMENTS.md` first. Follow the preferences there.
- Teach in easy language with practical, runnable examples. Each topic gets an "Example (problem)" and "Example (fix)" with real values.
- When the user asks to improve the plan, make the change in the files AND add a row to the improvement log in that file.
- Never invent a video or tutorial URL. Use a link only if it was verified (search or fetch). Otherwise label it as a search link in `RESOURCES.md`.
- Update `RAG-Mastery/PROGRESS.md` and `EVALUATION.md` when the user finishes a day or a quiz. Grade quizzes using `quizzes/answers/` and list weak topics.
- Don't show `quizzes/answers/` content before the user attempts the quiz.
- Keep chat replies short and plain; put long material in files.
