# Notes (one file per lesson)

After each lesson, Claude adds `day-XX-<topic>.md` here. Each note has:
1. Plain-language explanation of every concept from the lesson
2. Example (problem) and Example (fix) with real values
3. Real output from your own PC where possible
4. Errors you hit and how they were fixed
5. A short summary, a self-check, and a "My own notes" section for you

## How to get a note
Say "add notes for Day N" at the end of a lesson, or just ask a question and say "add this to the notes". Claude adds the explanation to the right day's file.
